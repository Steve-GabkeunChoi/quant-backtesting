# KRX CSV 백테스팅 앱

KRX 정보데이터시스템에서 내려받은 개별종목 시세추이 CSV 파일을 업로드해 투자 전략을 백테스팅하는 정적 웹 앱입니다.

외부 API를 호출하지 않고, 업로드된 CSV 파일만 사용합니다. GitHub Pages에 배포해 사용할 수 있습니다.

## 1. 프로젝트 구조

```text
quant-backtest-krx-generic/

├── docs/

├── README.md

```

## 2. 사용 데이터 기준

KRX 정보데이터시스템의 개별종목 시세추이 CSV를 사용합니다.

CSV 파일에는 다음 컬럼이 있어야 합니다.

```text
일자
종가
시가
고가
저가
거래량
```

KRX에서 내려받은 파일은 일반적으로 CP949/EUC-KR 인코딩입니다. 이 앱은 CP949/EUC-KR과 UTF-8 CSV를 처리합니다.

KRX CSV는 최신 날짜가 위에 있는 내림차순 형태일 수 있습니다. 앱 내부에서 과거 날짜에서 최신 날짜 순서로 자동 정렬한 뒤 백테스팅합니다.

## 3. 실행 방법

프로젝트 폴더에서 `index.html`을 브라우저로 열면 됩니다.

VS Code Live Server를 사용하는 경우 다음 순서로 실행합니다.

```text
1. 프로젝트 폴더 열기
2. index.html 우클릭
3. Open with Live Server 실행
```

GitHub Pages에 배포하는 경우 저장소에 파일을 업로드한 뒤 Pages 설정에서 배포 브랜치를 지정합니다.

## 4. CSV 준비 절차

KRX 정보데이터시스템에서 원하는 종목을 조회합니다.

```text
통계
기본 통계
주식
종목 시세
개별종목 시세추이
```

조회 조건을 설정합니다.

```text
종목명 또는 종목코드 입력
조회기간 설정
수정주가 적용 여부 선택
조회 클릭
다운로드 아이콘 클릭
CSV 파일 저장
```

저장한 CSV 파일을 앱의 `KRX CSV 파일 업로드`에서 선택합니다.

## 5. 백테스팅 절차

```text
1. 종목명 또는 종목코드 입력
2. KRX CSV 파일 업로드
3. 전략 선택
4. 전략별 조건 입력
5. 초기 투자금 입력
6. 거래 수수료율 입력
7. 백테스팅 실행
8. 결과 확인
```

`종목명 또는 종목코드` 입력값은 결과 화면 표시용입니다. 실제 계산은 업로드한 CSV 데이터 기준으로 수행합니다.

## 6. 지원 전략

### 이동평균 교차 전략

단기 이동평균선이 장기 이동평균선을 상향 돌파하면 매수합니다.

단기 이동평균선이 장기 이동평균선을 하향 이탈하면 매도합니다.

입력값입니다.

```text
단기 이동평균
장기 이동평균
```

### RSI 과매도·과매수 전략

RSI가 매수 기준 이하이면 과매도 구간으로 보고 매수합니다.

RSI가 매도 기준 이상이면 과매수 구간으로 보고 매도합니다.

입력값입니다.

```text
RSI 기간
매수 기준
매도 기준
```

### 변동성 돌파 전략

전일 가격 변동폭을 기준으로 당일 목표가를 계산합니다.

```text
목표가 = 전일 종가 + (전일 고가 - 전일 저가) × K
```

당일 고가가 목표가 이상이면 매수하고 당일 종가에 청산합니다.

입력값입니다.

```text
돌파 계수 K
```

## 7. 결과 지표

앱은 다음 결과를 출력합니다.

```text
최종 자산
누적 수익률
Buy & Hold 수익률
MDD
거래 횟수
승률
가격 차트
자산 곡선
거래 내역
```

### 최종 자산

초기 투자금으로 전략을 실행했을 때 백테스팅 종료 시점의 자산입니다.

### 누적 수익률

전략을 적용한 전체 기간의 수익률입니다.

### Buy & Hold 수익률

첫날 매수하고 마지막 날까지 보유했을 때의 수익률입니다.

### MDD

Maximum Drawdown입니다. 투자 기간 중 최고 자산 대비 가장 크게 하락한 비율입니다.

### 거래 횟수

전략 조건에 따라 발생한 매수와 매도 횟수입니다.

### 승률

청산된 거래 중 수익이 난 거래의 비율입니다.

## 8. 파일별 역할

### index.html

화면 구조를 정의합니다.

CSV 업로드, 전략 조건 입력, 결과 출력, 차트, 거래 내역 영역을 포함합니다.

### css/style.css

전체 화면 디자인을 정의합니다.

### js/app.js

화면 이벤트를 처리합니다.

CSV 파일 읽기, 인코딩 처리, 전략 선택 UI 전환, 백테스팅 실행, 결과 렌더링, 차트 출력을 담당합니다.

### js/backtest.js

CSV 파싱과 백테스팅 계산을 담당합니다.

이동평균, RSI, 변동성 돌파 전략 계산 함수가 포함되어 있습니다.
