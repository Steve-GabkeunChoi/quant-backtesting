# 백테스팅 시나리오

## 1. 기본 흐름

```text
KRX CSV 다운로드
CSV 파일 업로드
전략 선택
전략 조건 입력
초기 투자금과 수수료율 입력
백테스팅 실행
결과 해석
```

## 2. 시나리오 1: 이동평균 교차 전략

목적은 추세 추종 전략의 기본 구조를 확인하는 것입니다.

조건입니다.

```text
전략: 이동평균 교차 전략
단기 이동평균: 5
장기 이동평균: 20
초기 투자금: 10,000,000원
거래 수수료율: 0.00015
```

확인할 내용입니다.

```text
단기선이 장기선을 돌파하는 구간에서 매수 신호가 발생하는가
전략 수익률이 Buy & Hold 수익률보다 높은가
MDD가 어느 정도인가
거래 횟수가 과도하지 않은가
```

## 3. 시나리오 2: RSI 전략

목적은 과매도·과매수 기준의 역추세 전략을 확인하는 것입니다.

조건입니다.

```text
전략: RSI 과매도·과매수 전략
RSI 기간: 14
매수 기준: 30
매도 기준: 70
초기 투자금: 10,000,000원
거래 수수료율: 0.00015
```

확인할 내용입니다.

```text
RSI 기준을 낮추거나 높이면 거래 횟수가 어떻게 바뀌는가
수익률과 승률이 함께 개선되는가
단순 보유보다 위험이 줄어드는가
```

## 4. 시나리오 3: 변동성 돌파 전략

목적은 가격 돌파 기반 단기 매매 전략을 확인하는 것입니다.

조건입니다.

```text
전략: 변동성 돌파 전략
돌파 계수 K: 0.5
초기 투자금: 10,000,000원
거래 수수료율: 0.00015
```

확인할 내용입니다.

```text
K 값을 낮추면 거래가 증가하는가
K 값을 높이면 거래가 감소하는가
당일 청산 구조에서 수익률이 안정적인가
```

## 5. 종목 비교 실습

서로 다른 종목의 KRX CSV를 준비한 뒤 같은 전략 조건을 적용합니다.

비교 기준입니다.

```text
누적 수익률
Buy & Hold 수익률
MDD
거래 횟수
승률
```

이 비교를 통해 같은 전략이라도 종목 특성에 따라 성과가 달라진다는 점을 확인합니다.
