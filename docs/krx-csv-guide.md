# KRX CSV 준비 방법

## 1. KRX 정보데이터시스템 접속

KRX 정보데이터시스템에 접속합니다.

## 2. 메뉴 이동

다음 메뉴로 이동합니다.

```text
통계
기본 통계
주식
종목 시세
개별종목 시세추이
```

## 3. 종목 조회

조회할 종목명 또는 종목코드를 입력합니다.

예시입니다.

```text
삼성전자 005930
현대차 005380
NAVER 035420
카카오 035720
SK하이닉스 000660
LG에너지솔루션 373220
```

조회기간을 설정합니다.

```text
1개월
3개월
6개월
1년
직접 기간 입력
```

수정주가 적용 여부를 선택합니다.

장기 백테스팅에서는 수정주가 적용을 사용하는 것이 일반적입니다.

## 4. CSV 다운로드

조회 결과가 표시되면 화면 오른쪽의 다운로드 아이콘을 클릭합니다.

CSV 형식으로 저장합니다.

## 5. 앱에서 업로드

저장한 CSV 파일을 앱의 `KRX CSV 파일 업로드`에서 선택합니다.

앱은 다음 컬럼을 사용합니다.

```text
일자
시가
고가
저가
종가
거래량
```
